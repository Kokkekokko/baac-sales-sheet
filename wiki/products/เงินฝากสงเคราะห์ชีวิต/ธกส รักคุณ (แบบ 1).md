# ธกส รักคุณ แบบ 1

> [!summary] สรุป
> เงินฝากสงเคราะห์ชีวิตแบบ **คุ้มครองอุบัติเหตุส่วนบุคคล (PA) ระยะ 1 ปี** (มีลักษณะเช่นเดียวกับการประกันชีวิต **ไม่ใช่เงินฝาก** และ **ครบกำหนดไม่มีเงินคืน**) สำหรับเกษตรกรและครอบครัว อายุ 5–70 ปี
> เบี้ย **199 บาท/ปี ต่อทุน 100,000 บาท** (กรมธรรม์ละ 100,000 บาท รวมแบบ 1+2 ไม่เกิน 300,000 บาท/ราย)
> เสียชีวิต/ทุพพลภาพจากอุบัติเหตุรับ 100% ของทุน, สูญเสียอวัยวะ 1–100%, เสียชีวิตจากเจ็บป่วย (หลัง 90 วัน) รับ 10% (หน้า 1–3)

## ความคุ้มครอง (หน้า 2–3)
อุบัติเหตุที่ทำให้เสียชีวิต/ทุพพลภาพ/สูญเสียอวัยวะ ภายใน 180 วันนับแต่เกิดอุบัติเหตุ — จ่ายเป็น % ของทุนสงเคราะห์

| รายการ | % ของทุน |
|---|---|
| (1) เสียชีวิต | 100% |
| (2) ทุพพลภาพถาวรสิ้นเชิง | 100% |
| (3) มือ 2 ข้าง / เท้า 2 ข้าง / สายตา 2 ข้าง / มือ+เท้า / มือ+ตา / เท้า+ตา | 100% |
| (4) มือ 1 ข้าง / เท้า 1 ข้าง / สายตา 1 ข้าง | 60% |
| (5) หูหนวก 2 ข้าง หรือเป็นใบ้ | 50% |
| (6) หูหนวก 1 ข้าง | 15% |
| (7) นิ้วหัวแม่มือ (ทั้งสองข้อ) | 25% |
| (8) นิ้วหัวแม่มือ (หนึ่งข้อ) | 10% |
| (9) นิ้วชี้ (ทั้งสามข้อ) | 10% |
| (10) นิ้วชี้ (สองข้อ) | 8% |
| (11) นิ้วชี้ (หนึ่งข้อ) | 4% |
| (12) นิ้วอื่นแต่ละนิ้ว (≥ 2 ข้อ) | 5% |
| (13) นิ้วหัวแม่เท้า | 5% |
| (14) นิ้วเท้าอื่นแต่ละนิ้ว (≥ 1 ข้อ) | 1% |
| (15) **เสียชีวิตจากการเจ็บป่วย** (หลัง 90 วันนับแต่เริ่มสัญญาปีแรก) | 10% |

- จ่ายเพียงรายการสูงสุดรายการเดียว ยกเว้นสูญเสียนิ้ว (รายการ 7–14) ที่ไม่เข้ารายการ 1–4 จ่ายรวมตามจริงแต่ไม่เกินทุน
- ทุพพลภาพถาวรต้องต่อเนื่อง ≥ 180 วัน หรือมีข้อบ่งชี้ทางการแพทย์ชัดเจน; เหตุต้องไม่เกิดก่อนกรมธรรม์มีผล
- เสียชีวิตจากเจ็บป่วยภายใน 90 วันแรก ไม่ได้รับ 10% แต่คืนเบี้ยของรอบปีนั้นตามส่วน
- **ความคุ้มครองพิเศษ** (หน้า 3): คุ้มครองการเสียชีวิตจากการขับขี่/โดยสาร **รถจักรยานยนต์**, การถูกฆาตกรรม/ทำร้ายร่างกาย และ **การก่อการร้าย**; ผู้ที่อายุเกิน 70 ปีซึ่งชำระล่วงหน้าแล้วคุ้มครองถึงสิ้นปีนั้น แต่ต่ออายุไม่ได้

## การชำระ (หน้า 5–6)
- งวดแรก: เคาน์เตอร์ ธ.ก.ส., BAAC Mobile, ATM/CDM, Mobile Banking ทุกธนาคาร
- งวดต่ออายุ: หักบัญชี, BAACLife Online / A Insure (QR/Barcode), เคาน์เตอร์, BAAC Mobile, ATM/CDM; ภายนอก: Mobile Banking ทุกธนาคาร, เคาน์เตอร์เซอร์วิส 7-Eleven และตู้พร้อมเติม (มีค่าธรรมเนียม)
- ใบแจ้งชำระทางไปรษณีย์ล่วงหน้า 2 เดือน; SMS 1 ครั้งก่อนครบกำหนด 7 วัน
- ขาดผลบังคับแล้ว **ต่ออายุไม่ได้** ต้องสมัครใหม่ (หน้า 6)

## ข้อควรระวัง
- **ครบกำหนดไม่มีเงินคืน**, ไม่มีระยะผ่อนผัน — จ่ายช้าแม้วันเดียวความคุ้มครองสิ้นสุด
- ธนาคารบอกเลิกได้ (แจ้งล่วงหน้า ≥ 30 วัน) หากพบการทุจริต; กรมธรรม์สิ้นสุดอัตโนมัติเมื่อผู้ฝากถูกจองจำในเรือนจำ/ทัณฑสถาน (คืนเบี้ยตามส่วน) (หน้า 4)
- ข้อยกเว้น (หน้า 4–5): ตั้งครรภ์/คลอด/แท้ง; ดำน้ำ/ล่าสัตว์; แข่งขัน/พนัน/ผาดโผน; ยานพาหนะไม่จดทะเบียนโดยสาร; ถูกผู้รับประโยชน์ทำร้าย; ฆ่าตัวตาย/ทำร้ายตนเอง; เมาสุรา (แอลกอฮอล์ในเลือด ≥ 50 มิลลิกรัมเปอร์เซ็นต์) หรือยาเสพติด; ทะเลาะวิวาท; ติดเชื้อโรค/ปรสิต; การรักษาทางเวช/ศัลยกรรมที่ไม่เกี่ยวกับอุบัติเหตุ; นิวเคลียร์; สงคราม/รัฐประหาร/กฎอัยการศึก/จลาจล; กระทำผิดอาญา; ทหาร/ตำรวจ/อาสาสมัครปฏิบัติการสงครามหรือปราบปรามเกิน 30 วัน
- ผู้สมัครอายุ 5–<20 ปีต้องมีบิดา/มารดา/ผู้แทนโดยชอบธรรมลงนามยินยอม (หน้า 6)
