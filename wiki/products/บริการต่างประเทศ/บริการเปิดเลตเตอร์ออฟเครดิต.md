# บริการเปิดเลตเตอร์ออฟเครดิต (Issue/Open L/C)

> [!summary] สรุป
> บริการด้านนำเข้า: ธ.ก.ส. เปิด [[เลตเตอร์ออฟเครดิต (LC)|L/C]] ไปยังผู้ขายในต่างประเทศผ่านธนาคารของผู้ขาย และจะชำระเงินให้ผู้ขายเมื่อผู้ขายปฏิบัติตามเงื่อนไขใน L/C ครบถ้วน ลูกค้าต้องมีวงเงิน L/C หรือสินเชื่อกับธนาคาร ค่าธรรมเนียมเปิด 0.25% ต่อทุก 3 เดือน (ขั้นต่ำ 1,000 บาท) + ค่า SWIFT MT700 1,000 บาท (หน้า 1)

## ข้อมูลสำคัญ
| หัวข้อ | รายละเอียด |
|---|---|
| ประเภทบริการ | บริการด้านนำเข้า (Import) (หน้า 1) |
| ประเภท L/C | **L/C Sight** — ชำระเงินทันทีเมื่อธนาคารได้รับเอกสาร ลูกค้าต้องชำระทันทีเมื่อเอกสารมาถึง หรือขอวงเงินสินเชื่อกับธนาคาร · **L/C Term** — ผู้ขายให้ระยะเวลาชำระเงิน ลูกค้าต้องมีวงเงินสินเชื่อกับธนาคาร และชำระเมื่อตั๋วครบกำหนด (หน้า 1) |
| กลุ่มลูกค้า | ผู้ประกอบการนำเข้าสินค้าจากต่างประเทศ (หน้า 1) |
| ระยะเวลาดำเนินการ | ส่งคำสั่งเปิด L/C ให้ธนาคารต่างประเทศอย่างช้าภายในวันทำการถัดไป (หน้า 1) |
| เอกสาร | ใบคำขอเปิดเลตเตอร์ออฟเครดิต; สำเนาเอกสารการซื้อขายอย่างใดอย่างหนึ่ง: Purchase Order / Sale Contract / Proforma Invoice (หน้า 1) |
| เงื่อนไข | ต้องมีวงเงิน L/C หรือสินเชื่อที่เกี่ยวข้องกับธนาคาร; ยื่นเอกสารได้ที่สาขา (หน้า 1) |
| ช่องทาง | ทุกสาขาทั่วประเทศ (หน้า 1) |
| อัตราแลกเปลี่ยน | ไม่ระบุในเอกสาร (ตัวอย่างใช้ USD1 = 32 บาท เพื่อคำนวณเท่านั้น) |

## ค่าธรรมเนียม
| รายการ | อัตรา |
|---|---|
| ค่าธรรมเนียมเปิด L/C | 0.25% ของจำนวนเงินที่เปิด ต่อระยะเวลา 3 เดือน ขั้นต่ำ 1,000 บาท; เศษของระยะเวลาคิดเป็น 3 เดือน (หน้า 1) |
| ค่า SWIFT เปิด L/C | MT700 = 1,000 บาท/ฉบับ; MT701 = 400 บาท/ฉบับ (หน้า 1) |
| ค่าธรรมเนียมยกเลิก L/C | 400 บาท/ฉบับ (หน้า 1) |
| ค่าแก้ไข L/C | มีค่าธรรมเนียมแก้ไข + ค่า SWIFT การแก้ไข — อัตราไม่ระบุในเอกสาร (หน้า 2) |

**ตัวอย่าง (หน้า 1):** เปิด L/C มูลค่า USD150,000 วันที่ออก 15/12/2019 หมดอายุ 15/3/2020 (90 วัน ไม่เกิน 3 เดือน) อัตรา USD1 = 32 บาท → 4,800,000 บาท × 0.25% = 12,000 บาท + SWIFT 1,000 บาท = **รวม 13,000 บาท**

## ข้อควรระวัง
- หากเปลี่ยนแปลง/แก้ไข L/C จะถูกเรียกเก็บค่าธรรมเนียมแก้ไขและค่า SWIFT จากการแก้ไข (หน้า 2)
- ค่าธรรมเนียมคิดตามช่วง 3 เดือน — L/C อายุเกิน 3 เดือนแม้เพียงไม่กี่วันจะถูกคิดเพิ่มอีกช่วง (หน้า 1)
- เมื่อเอกสารมาถึงจะมีค่าธรรมเนียมขั้นตอนชำระเงินอีกชุด ดู [[บริการชำระเงินตามเอกสารขาเข้าภายใต้ LC]]
- การเปลี่ยนแปลงเงื่อนไข: ตามประกาศธนาคาร (หน้า 2)

## ช่องทางติดต่อ
ธ.ก.ส. ทุกสาขา หรือ Call Center 02-555-0555 (หน้า 2)
