# บริการโอนเงินต่างประเทศขาออกผ่าน Mobile

> [!summary] สรุป
> โอนเงินไปต่างประเทศด้วยตนเองผ่านแอป [[BAAC Mobile]] สำหรับบุคคลธรรมดาสัญชาติไทยอายุ 15 ปีขึ้นไปที่ผ่าน e-KYC รองรับ 3 สกุลเงิน (USD, EUR และ THB สำหรับ สปป.ลาว) วงเงินไม่เกิน 150,000 บาทต่อรายการต่อคน และไม่เกิน 1 ล้านบาทต่อวัน สแกนใบหน้าทุกรายการ เปิดบริการ 08.30–16.00 น. วันทำการ ค่าธรรมเนียมเท่ากับอัตราโอนผ่านเคาน์เตอร์ (หน้า 1–2, 4)

## ข้อมูลสำคัญ
| หัวข้อ | รายละเอียด |
|---|---|
| คุณสมบัติผู้ใช้ | บุคคลธรรมดาสัญชาติไทย อายุ 15 ปีบริบูรณ์ขึ้นไป; ลงทะเบียนพิสูจน์และยืนยันตัวตนทางอิเล็กทรอนิกส์ (e-KYC); 1 CIF ลงทะเบียนได้ 1 หมายเลขโทรศัพท์; บัญชีเงินฝากเจ้าของคนเดียว (Single) สถานะ Active ไม่ติดอายัด (หน้า 1) |
| เวลาให้บริการ | 08.30–16.00 น. (ยกเว้นวันหยุดและวันหยุดนักขัตฤกษ์) (หน้า 1) |
| สกุลเงิน (3) | USD; EUR; THB (สำหรับ สปป.ลาว) (หน้า 2) |
| วงเงิน | ไม่เกิน 150,000 บาทต่อรายการต่อคน และไม่เกิน 1 ล้านบาทต่อวัน (หน้า 2) |
| การยืนยันตัวตน | สแกนใบหน้า (Biometric) ทุกรายการก่อนอนุมัติ; ตรวจสอบ Sanction List (รายบุคคลและประเทศ) (หน้า 2–3) |
| ค่าธรรมเนียม | ตามอัตราค่าธรรมเนียมโอนเงินต่างประเทศขาออกผ่านเคาน์เตอร์ ธ.ก.ส. (ดู [[บริการโอนเงินต่างประเทศขาออก]]) แสดงบนหน้าจอให้ยืนยันก่อนทำรายการ (หน้า 4) |
| ระยะเวลาเงินถึงปลายทาง | ไม่ระบุในเอกสาร |
| อัตราแลกเปลี่ยน | ไม่ระบุในเอกสาร |

## วัตถุประสงค์การโอนที่เปิดให้บริการ (หน้า 1)
1. ค่าใช้จ่ายการท่องเที่ยว
2. ค่าการศึกษา
3. ค่าใช้จ่ายด้านสุขภาพ
4. รายได้และเงินออม
5. เงินให้แก่บุคคลในต่างประเทศ (ไม่เกินปีละ USD200,000 หรือเทียบเท่า)
6. ส่งเงินให้ครอบครัวหรือญาติที่มีถิ่นพำนักถาวรในต่างประเทศ
7. ค่าสินค้าเข้าและสินค้าออก

## ข้อมูล/เอกสาร (สำหรับติดต่อสาขาหรือ Call Center) (หน้า 1)
หลักฐานแสดงตนที่มีรูปถ่ายออกโดยราชการ (ยังไม่หมดอายุ) · ชื่อผู้รับเงิน · เลขบัญชี/IBAN (ถ้ามี) · ที่อยู่ผู้รับเงิน · ธนาคารปลายทาง · SWIFT Code ธนาคารปลายทาง · วัตถุประสงค์การโอน (ถ้ามี)

## ฟังก์ชันในแอป (หน้า 2–4)
- สร้างรายการโอนและตรวจสอบประวัติ (Transaction History); การแก้ไขรายการต้องติดต่อสาขา/Call Center ให้สำนักงานใหญ่ส่งคำสั่งแก้ไขไปธนาคารปลายทาง
- เพิ่มรายการโปรด (Add Favorite) ได้หลังรายการมีสถานะ Complete; โอนจากรายการโปรดแก้ไขจำนวนเงิน/วัตถุประสงค์ได้ แต่ต้องระบุผู้รับภาระค่าธรรมเนียมใหม่ทุกครั้ง
- ความปลอดภัย: ยืนยันตัวตนก่อนเข้าระบบทุกครั้ง; ปกปิดเลขบัญชีบนหน้าจอ; Session Timeout แล้วต้องสแกนใบหน้าใหม่; แจ้งผลทันทีทั้งสำเร็จ/ไม่สำเร็จ และส่ง e-mail แจ้งเมื่อรายการผิดพลาด

## ข้อควรระวัง
- กรอกข้อมูลไม่ถูกต้องครบถ้วนจนเงินเข้าบัญชีปลายทางไม่ได้ การแก้ไขจะมีค่าบริการเพิ่ม (หน้า 4)
- รองรับเพียง 3 สกุลเงิน — สกุลอื่นต้องใช้บริการที่สาขา (หน้า 2)
- การเปลี่ยนแปลงเงื่อนไขจะประกาศในช่องทางของธนาคารและในหน้า BAAC Mobile (หน้า 4)

## ช่องทางติดต่อ
ธ.ก.ส. ทุกสาขา หรือ Call Center 02-555-0555 (หน้า 4)
