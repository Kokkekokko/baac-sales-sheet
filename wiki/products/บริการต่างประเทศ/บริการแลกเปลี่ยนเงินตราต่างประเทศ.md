# บริการแลกเปลี่ยนเงินตราต่างประเทศ (Money Exchange)

> [!summary] สรุป
> รับซื้อ/ขายธนบัตรเงินตราต่างประเทศ 16 สกุล ไม่มีค่าธรรมเนียมการแลกเปลี่ยน มีบริการรับแลกนอกสถานที่ ใช้บัตรประชาชนหรือพาสปอร์ต ปัจจุบันงดรับซื้อธนบัตร DKK, NOK, SEK และ TWD ชั่วคราว การขายเงินตราต่างประเทศขึ้นกับว่าจุดบริการมีเงินสำรองหรือไม่ (หน้า 1–2)

## ข้อมูลสำคัญ
| หัวข้อ | รายละเอียด |
|---|---|
| สกุลเงิน (16) | AUD, CAD, CHF, CNY, DKK, EUR, GBP, HKD, JPY, KRW, NOK, NZD, SEK, SGD, TWD, USD (หน้า 1) |
| งดรับซื้อชั่วคราว | ธนบัตร DKK, NOK, SEK, TWD (หน้า 1) |
| คู่ค้า | รับซื้อ/ขายกับลูกค้า ธนาคารพาณิชย์ และตัวแทนรับอนุญาต (หน้า 1) |
| ค่าธรรมเนียม | ไม่มี (หน้า 1–2) |
| กลุ่มลูกค้า | นักท่องเที่ยวต่างชาติ; ชาวต่างชาติที่ทำงานในไทย; ลูกค้าที่มีคนในครอบครัว/คู่สมรสเป็นชาวต่างชาติ; ลูกค้าที่มีคนในครอบครัวไปทำงานต่างประเทศ; หน่วยงานราชการและรัฐวิสาหกิจที่ไปศึกษาดูงานต่างประเทศ (หน้า 1) |
| เอกสาร | หลักฐานแสดงตนที่มีรูปถ่ายออกโดยราชการ (ยังไม่หมดอายุ): บัตรประจำตัวประชาชน หรือหนังสือเดินทาง (หน้า 1) |
| เวลาให้บริการ | จันทร์–ศุกร์ ในเวลาทำการ; เสาร์–อาทิตย์ ในเวลาทำการ (เฉพาะจุดบริการที่เปิดเสาร์–อาทิตย์) (หน้า 2) |
| จุดให้บริการ | ตรวจสอบได้ที่ https://www.baac.or.th หรือ QR Code ในเอกสาร (หน้า 2) |
| อัตราแลกเปลี่ยน | ไม่ระบุในเอกสาร (ตามที่ธนาคารประกาศ) |

## หลักเกณฑ์และเงื่อนไข (หน้า 1)
- **ไม่รับซื้อธนบัตร:** รุ่นที่ยกเลิก, ปลอม, มีรอยฉีกขาด, รอยยับ, สภาพเก่าไม่พร้อมใช้งาน, รอยเปรอะเปื้อน, รอยขีดเขียน, รอยเย็บ, ชำรุด และมีตราประทับ
- จุดบริการที่ **มี** เงินตราต่างประเทศสำรอง ขายให้ลูกค้าได้ตามหลักเกณฑ์ธนาคาร; จุดที่ **ไม่มี** สำรอง อาจขายให้ไม่ได้
- รับซื้อมูลค่าตั้งแต่ **USD15,000** หรือเทียบเท่า ธนาคารอาจขอเอกสารแสดงที่มาของเงินตราที่นำเข้าประเทศ

## ข้อควรระวัง
- ควรตรวจสอบจุดบริการและเงินสำรองก่อนเดินทาง หากต้องการ **ซื้อ** เงินตราต่างประเทศ (หน้า 1)
- ธนบัตรสภาพไม่ดีจะถูกปฏิเสธ (หน้า 1)

## ช่องทางติดต่อ
Call Center 0-2555-0555 หรือ กลุ่มงานปริวรรตและโอนเงินด่วนระหว่างประเทศ สำนักธุรกิจต่างประเทศ โทร 0-2558-6555 ต่อ 6036–6037 (หน้า 2)
