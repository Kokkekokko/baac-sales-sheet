# เงินฝากออมทรัพย์ทวีโชค

> [!summary] สรุป
> บัญชีเงินฝากออมทรัพย์พื้นฐานสำหรับ **เกษตรกรลูกค้าผู้กู้** ของ ธ.ก.ส. เปิดที่เคาน์เตอร์สาขาขั้นต่ำ 50 บาท ฝาก-ถอนไม่จำกัด ดอกเบี้ยตามประกาศธนาคาร ทบต้นปีละ 2 ครั้ง บุคคลธรรมดายกเว้นภาษี ใช้รับเงินกู้/สวัสดิการ ผูกบัตร ATM/เดบิต BAAC Mobile และใช้เป็นหลักประกันเงินกู้ได้ (หน้า 1)

## ข้อมูลสำคัญ
| หัวข้อ | รายละเอียด |
|---|---|
| ประเภท | เงินฝากประเภทออมทรัพย์ (หน้า 1) |
| คุณสมบัติ (เปิดใหม่) | เกษตรกรลูกค้าผู้กู้ (หน้า 1) |
| ประเภทบัญชี | เจ้าของคนเดียว (Single) เปิดผ่านเคาน์เตอร์สาขา (หน้า 1) |
| เงินฝากขั้นต่ำ/สูงสุด | เปิดบัญชีขั้นต่ำ 50 บาท ไม่จำกัดสูงสุด (หน้า 1) |
| อัตราดอกเบี้ย | ตามประกาศอัตราดอกเบี้ยเงินฝากของธนาคาร (www.baac.or.th) — ตัวเลขไม่ระบุในเอกสาร (หน้า 1) |
| การจ่ายดอกเบี้ย | ทบต้นปีละ 2 ครั้ง (มี.ค. และ ก.ย.) คำนวณสะสมรายวัน (หน้า 1) |
| ภาษี | บุคคลธรรมดาได้รับยกเว้นภาษีดอกเบี้ยเงินฝาก (หน้า 1) |
| การฝาก | ที่เคาน์เตอร์สาขาไม่จำกัดจำนวนเงิน/ครั้ง; ผ่าน CDM ตามเงื่อนไขเครื่อง; ฝากต่างสำนักงานเสียค่าธรรมเนียมตามประกาศ (หน้า 1) |
| การถอน | ไม่จำกัดจำนวนเงินและจำนวนครั้ง; ถอนต่างสำนักงานต้องทำด้วยตนเอง เสียค่าธรรมเนียมตามประกาศ (หน้า 1) |
| การใช้งาน | รับโอนเงินกู้ เงินสวัสดิการ รับโอนสลากออมทรัพย์ หักชำระค่าใช้จ่าย; ผูกบัตร ATM/บัตรเดบิต; ผูก BAAC Mobile และ QR Code แอป "ร้านน้องหอมจัง"; ใช้เป็นหลักประกันเงินกู้ตามข้อบังคับฉบับ 35 (หน้า 1) |
| ค่ารักษาบัญชี | ตามประกาศอัตราค่าบริการและค่าธรรมเนียมของธนาคาร (หน้า 1) |
| ปิดบัญชี | ที่สาขาเจ้าของบัญชีเท่านั้น; ปิดอัตโนมัติเมื่อยอด 0 บาทและไม่เคลื่อนไหวเกิน 12 เดือน **ยกเว้น** บัญชีลูกค้าเกษตรกรผู้กู้ตามข้อบังคับฉบับที่ 44 (หน้า 1) |
| ช่องทาง | ธ.ก.ส. สาขา, Call Center 0-2555-0555 (24 ชม.), 1593, www.baac.or.th (หน้า 1) |

## การคำนวณดอกเบี้ย
ดอกเบี้ยสะสมรายวัน = เงินฝากคงเหลือสิ้นวัน × (อัตรา/100) × (ระยะเวลาฝาก/365 หรือ 366) (หน้า 1)

## ข้อควรระวัง
- ทำรายการต่างสาขามีค่าธรรมเนียมตามประกาศ — [[ค่าธรรมเนียม]] (หน้า 1–2)
- อัตราดอกเบี้ยไม่ได้ระบุไว้ในเอกสาร ต้องตรวจสอบประกาศล่าสุด
