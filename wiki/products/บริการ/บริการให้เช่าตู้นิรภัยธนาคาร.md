# การให้บริการเช่าตู้นิรภัยธนาคาร

> [!summary] สรุป
> บริการให้เช่าตู้นิรภัยเพื่อเก็บรักษาทรัพย์สินมีค่า (โฉนด พินัยกรรม กรมธรรม์ ทองคำ ฯลฯ) **มีเฉพาะที่สาขาบางเขน** เปิดให้ลูกค้าหรือบุคคลทั่วไปที่มีบัญชีออมทรัพย์ ธ.ก.ส. (ไว้หักค่าเช่ารายปี)
> มี 3 ขนาด ค่าเช่า **1,200 / 2,400 / 3,600 บาทต่อปี** (ตั้งแต่ 1 ต.ค. 2569) บวกค่ามัดจำกุญแจ **3,500 บาทต่อช่อง** (หน้า 1)

## ข้อมูลสำคัญ
| หัวข้อ | รายละเอียด |
|---|---|
| ผู้ใช้บริการ | ลูกค้า หรือบุคคลทั่วไป ต้องมีบัญชีเงินฝากออมทรัพย์ (ใช้หักค่าบริการรายปี) (หน้า 1) |
| สถานที่ / เวลา | **เฉพาะสาขาบางเขน** เปิดบริการทุกวันในเวลาทำการของธนาคาร (หน้า 1, หน้า 2) |
| เอกสาร | 1) บัตรประชาชนแบบชิปการ์ด 2) หนังสือเดินทาง (กรณีชาวต่างชาติ) 3) สมุดบัญชีเงินฝากออมทรัพย์ ธ.ก.ส. (หน้า 1) |
| ขนาดตู้ | 3 ขนาด (สูง x กว้าง x ลึก): 3x10x21, 5x10x21, 10x10x21 นิ้ว (หน้า 1) |
| ค่าเช่า | 1,200 – 3,600 บาท/ปี ตามขนาด (หน้า 1) |
| การชำระค่าเช่า | ปีแรกชำระเป็น **เงินสด** ล่วงหน้า 1 ปี ณ วันทำสัญญา ปีต่อ ๆ ไปหักผ่านบัญชีเงินฝาก ธ.ก.ส. (หน้า 1) |
| ค่ามัดจำกุญแจ | 3,500 บาท ต่อช่องฝาก (ประกันความสูญหายหรือชำรุด) (หน้า 1) |
| อ้างอิง | ประกาศอัตราค่าบริการและค่าธรรมเนียมธนาคาร (หน้า 2) |

## ค่าธรรมเนียม
ค่าเช่าต่อปี ตั้งแต่วันที่ 1 ตุลาคม 2569 (หน้า 1)

| ขนาดช่องฝาก (สูง x กว้าง x ลึก) | ค่าเช่า |
|---|---|
| 3x10x21 นิ้ว | 1,200 บาท/ปี |
| 5x10x21 นิ้ว | 2,400 บาท/ปี |
| 10x10x21 นิ้ว | 3,600 บาท/ปี |

ค่าใช้จ่ายอื่น (หน้า 1)
- ค่ามัดจำลูกกุญแจ: 3,500 บาท/ช่องฝาก
- ค่าทำลูกกุญแจใหม่ กรณีชำรุด/สูญหาย: ลูกค้าชำระตามที่จ่ายจริง
- ค่าทำลายตู้นิรภัย: ลูกค้าชำระตามที่จ่ายจริง

## การยกเลิกระหว่างปีและการคืนค่าบริการ
ธนาคารคืนค่าบริการเป็นรายเดือน **เศษของวันคิดเป็นหนึ่งเดือน** รับคืนเป็นเงินสดหรือโอนเข้าบัญชี ธ.ก.ส. (หน้า 2)

สูตร: ค่าบริการที่คืน = (ค่าบริการรายปี / 12) x จำนวนเดือนที่ไม่ได้ใช้บริการ

ตัวอย่างในเอกสาร (หน้า 2): เช่า 1 เม.ย. 2569 อัตรา 1,000 บาท/ปี ยกเลิก 10 ส.ค. 2569 → ใช้บริการ 4 เดือน 10 วัน = นับ 5 เดือน → คืน 7 เดือน = (1,000/12) x 7 = **583.33 บาท**

> [!note] ตัวอย่างใช้อัตรา 1,000 บาท/ปี สำหรับ "ตู้ขนาดใหญ่" ซึ่งไม่ตรงกับตารางค่าเช่าปัจจุบัน (ขนาดใหญ่สุด 3,600 บาท/ปี) — ถือเป็นตัวเลขสมมติเพื่อสาธิตสูตรเท่านั้น

## ทรัพย์สินที่เก็บได้ / ข้อห้าม
- เก็บได้: โฉนดที่ดิน พินัยกรรม กรมธรรม์ เครื่องประดับ ทองคำ ของสะสมมีค่า และสิ่งของมีค่าอื่นที่ไม่ขัดต่อกฎหมาย (หน้า 2)
- ห้ามเก็บ: วัตถุระเบิด ของเหลว ของผิดกฎหมาย ของอันตราย หรือสิ่งที่อาจก่อความเดือดร้อนรำคาญ (หน้า 2)

## ข้อควรระวัง
- สิ่งของที่เก็บต้องเป็นกรรมสิทธิ์ของผู้เช่า หากเจ้าหน้าที่สงสัย ผู้เช่าต้องยินยอมให้ธนาคารตรวจดู (หน้า 2)
- ผู้เช่า **ไม่มีสิทธิ์ให้เช่าช่วง** ตู้นิรภัยต่อบุคคลอื่น (หน้า 2)
- กุญแจหาย/ชำรุด หรือต้องทำลายตู้ ลูกค้าจ่ายตามจริง นอกเหนือจากเงินมัดจำ (หน้า 1)
- ความคุ้มครอง/ประกันภัยทรัพย์สินในตู้: ไม่ระบุในเอกสาร
