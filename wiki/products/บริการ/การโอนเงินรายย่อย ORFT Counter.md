# การโอนเงินรายย่อย ORFT Counter

> [!summary] สรุป
> บริการโอนเงินระหว่างธนาคารที่ **เคาน์เตอร์ ธ.ก.ส. ทุกสาขา** ครั้งละ **ไม่เกิน 100,000 บาท** ไม่จำกัดจำนวนครั้ง ผู้รับได้เงิน **ทันที (Real Time)**
> ค่าบริการขั้นบันไดตามยอดโอน **50–120 บาท/รายการ** ใช้ได้ทั้งบุคคลทั่วไปและนิติบุคคล (หน้า 1)

## ข้อมูลสำคัญ
| หัวข้อ | รายละเอียด |
|---|---|
| ผู้ใช้บริการ | บุคคลทั่วไป และนิติบุคคล (หน้า 1) |
| ช่องทาง | เคาน์เตอร์ ธ.ก.ส. ทุกสาขา (หน้า 1) |
| เวลาให้บริการ | ทุกวัน ในเวลาทำการของธนาคาร (cut-off เป็นเวลาเฉพาะ: ไม่ระบุในเอกสาร) (หน้า 1) |
| วงเงิน | ไม่เกิน **100,000 บาท/ครั้ง** ไม่จำกัดจำนวนครั้ง (หน้า 1) |
| ระยะเวลาเงินเข้า | ทันที (Real Time) (หน้า 1) |
| วิธีชำระ | เงินสด หรือหักจากบัญชีเงินฝาก (หน้า 1) |
| เอกสาร/ข้อมูล | บัตรประชาชนผู้โอน · ชื่อ-นามสกุลผู้รับ · ชื่อธนาคารปลายทาง, เลขที่บัญชีปลายทาง, จำนวนเงิน (หน้า 1) |
| ต้องมีบัญชี ธ.ก.ส. หรือไม่ | ไม่ระบุในเอกสาร (ระบุว่าโอนด้วยเงินสดได้) |

## ค่าธรรมเนียม
คิดตามช่วงมูลค่าการโอนต่อรายการ ขั้นต่ำ 50 บาท – สูงสุด 120 บาท (หน้า 1)

| มูลค่าการโอน (บาท/รายการ) | ค่าบริการ (บาท/รายการ) |
|---|---|
| > 0 – ≤ 10,000 | 50 |
| > 10,000 – ≤ 20,000 | 60 |
| > 20,000 – ≤ 30,000 | 70 |
| > 30,000 – ≤ 40,000 | 80 |
| > 40,000 – ≤ 50,000 | 90 |
| > 50,000 – ≤ 65,000 | 100 |
| > 65,000 – ≤ 80,000 | 110 |
| > 80,000 – ≤ 100,000 | 120 |

## ข้อควรระวัง
- ตรวจสอบและยืนยันชื่อ–เลขที่บัญชีผู้รับให้ถูกต้องก่อนโอนทุกครั้ง (หน้า 2)
- หากแจ้งข้อมูลผิด ธนาคารจะประสานธนาคารปลายทางขอคืนเงิน **ไม่คืนค่าบริการ** และใช้เวลาติดตาม **ภายใน 20 วันทำการ** (หน้า 2)
- โอนสำเร็จแล้ว **แก้ไขหรือยกเลิกไม่ได้** (หน้า 2)
- ยอดเกิน 100,000 บาทต้องแบ่งหลายรายการ (เสียค่าบริการต่อรายการ) หรือใช้ [[การโอนเงินเพื่อบุคคลที่สาม BAHTNET]] ซึ่งไม่จำกัดวงเงิน
